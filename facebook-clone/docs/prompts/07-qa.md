## Functional and state check

On web and iOS from fresh state, verify identical seed counts and order. Then post text and a local photo, react/unreact, comment, save/unsave, search every content type, confirm/delete friend requests, mark/read notifications, send a local message, save/open a listing, and change every functional Settings value. Refresh the browser or relaunch each native app between groups of actions. Test reset and confirm that only the clone's key and owned photo files are removed. Walk every visible navigation item, browser direct-refresh/back, and native Back/close behavior. Check malformed storage and photo-write/size failure paths with focused checks if persistence logic is nontrivial. Inspect web and native runtime requests for external image/API calls; documentation links are allowed, runtime hotlinks are not.

## Build, accessibility, and handoff

Run web and native type/bundle checks and existing tests, and launch iOS in their native runtimes. Check web icon-button names/keyboard/Escape/focus and native accessibility labels/touch targets/Back/keyboard avoidance; check dark-mode contrast, image descriptions, and reduced motion on both. Verify the root README includes the unofficial-demo notice and web/iOS run/reset steps. Leave web captures plus `docs/verification/native-ios/` captures and a short verification README with exact commands/results, tested actions, and remaining visual differences. Report only completed checks; do not claim native completion from a browser screenshot or bundle command alone.
