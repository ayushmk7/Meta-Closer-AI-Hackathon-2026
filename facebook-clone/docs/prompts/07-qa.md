## Functional and state check

Then post text and a local photo, react/unreact, comment, save/unsave, search every content type, confirm/delete friend requests, mark/read notifications, send a local message, save/open a listing, and change every functional Settings value. Refresh between groups of actions. Test reset and confirm that only the clone key is removed. Walk every visible navigation item and direct-refresh/back behavior.
